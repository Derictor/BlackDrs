# Sandman

Black Drs é o Senhor dos Sonhos e pertence à classe única Sandman. Usa areia para atrasar inimigos em desafios mentais e espirituais e dispara projéteis à distância em Balas do Matrix. Destino, Fé, Sabedoria, Encantar e Beleza aparecem na progressão.

Morfeu aparece nos encontros noturnos. A ampulheta, a areia ritual e o colar podem ser obtidos em eventos. As receitas de pesquisa incluem também a máscara, a pipoca onírica e o espírito de areia.

Copie a pasta BlackDrs para Thea2_Data/StreamingAssets/Mods e habilite o mod no menu do jogo. A arte usa roxo, azul escuro e âmbar. Para recriá-la, rode python tools/generate_art.py com Pillow instalado.
